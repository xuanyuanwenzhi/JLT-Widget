# JLT-Widget（笺礼甜）

一个 Android 桌面小组件合集（测试版）。

目前包含 3 种小组件：
- 🎋 竹筒：点击触发抽签动画 + 祝福语
- ⭐ 星星瓶：点击触发抽签动画 + 祝福语
- 🌦️ 天气/时间：根据时间段与天气类型切换动画与语录（支持多数据源解析）

---

## 使用教程（添加到桌面）

不同手机系统叫法可能不一样，大致流程一致：

1. **长按桌面空白处**
2. 选择：`卡片 / 插件 / 小组件 / Widget`（任选其一，名称按你的系统为准）
3. 在列表里找到 **笺礼甜** 相关小组件
4. **长按并拖到桌面**即可使用
5. 小组件一般 **点击就能触发功能**

> 注：第一次点击可能会打开 App 界面，点击复原返回桌面再点一下通常就恢复正常。  
> 再注：如果你在抽签类小组件里“连续点击复原”，可能会清除点击次数/状态，请谨慎操作。  
> 再再注：天气小组件当前版本暂时没做点击次数统计，后续版本会补上。

---

## 天气数据来源

天气获取目前支持两种数据源解析：
- **wttr**
- **聚合接口**

> 说明：天气小组件点击可触发刷新（即使后台自动刷新关闭，也不影响点击刷新）。
